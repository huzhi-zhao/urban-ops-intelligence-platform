## 1. 背景

### 1.1 现有唯一把模型和计划放在一起的产物，回答不了「计划与需求对不对得上」

M1 进入对外产出的唯一路径是 F6 → F7：预测请求量构成 `load_score` 的 0.40 权重项，
推荐层按分数排序（[business-objectives.md](../requirements/business-objectives.md)
BO-8 表述纪律第 2 条的标准答复就是这条链）。

伞篇 §3.6 实测了这条链在**事件内部**的形状——也就是推荐层真正消费的那个粒度：

| | 相邻对 | 分差中位 |
|---|---:|---:|
| 跨班次 | 68 | **5.77** |
| 同班次 | 289 | **0.106** |

班次把 22 个分区切成 5 个台阶，台阶高 6 分；M1 只在台阶内部把分区拨来拨去，
幅度是台阶高度的 **1/54**。**`load_score` 的事件内排序，粗粒度上就是排班表本身。**

由此有两条推论，都不依赖权重取多少：

1. 计划就在分数里面，所以这个分数**不可能**回答「计划跟需求对不对得上」——
   问题和答案被写进了同一个式子。
2. 对外说「排序由模型预测驱动」，而事件内排序里模型的声音只剩 0.106 分。
   **对外表述与实际机制不符**，这是比「权重是拍的」更直接的问题。

### 1.2 能打分的量从未被单独拿出来

伞篇 §0 已经分清：M1 这一层**有答案可对**（`fact_request_forecast.actual_count`
与预测同行存放），评分那一层**没有**。现状是把能打分的量（预测请求数）塞进一个
不能打分的量（负载分数）里，于是前者的可检验性也跟着丢了。

### 1.3 伞篇 §1 一直留白

13 条需求因此无法排序；2026-09-24 的取舍只给出了「与方向无关」的部分。
需要一个判据。

## 2. 决策

**H2 完成 = 读者对一场已经过去的降雪、一个作业分区，能在同一处看到三样东西，
每样都不越过证据：**

1. **公开计划**：该分区在那次作业里的计划班次（1–5），写明是计划、不是完成时间
   （ADR 0008）；
2. **需求估计**：M1 对该格上报请求数的估计，**带区间**，标为回测估计，
   并与事后的实际计数并排；
3. **来源**：数据日期、模型版本、事件规则版本、查询、认证状态。

在此之上，按一条**公开且先于结果登记**的规则给出**复核提示**：
需求强度高、班次靠后、且在重采样下稳定的分区。它是提示，不是结论。

### 2.1 三条随之而来的纪律

**① 需求与计划分栏，不合成一个分数。** 计划不进入需求估计（M1 本来如此，
班次不在特征里），需求估计也不再进入任何含计划的分数。
F6 的 `load_score` 与 F7 的 `rank_delta` 退为**历史方法**：保留、可查，
不再作为 H2 产出，也不再扩展。

**② 模型输出以回测估计的身份进入页面。** 这推翻 ADR 0013 §2.2 第 2 条
（「两个都不是模型输出」）。条件四条，缺一不上页面：

| | 条件 | 出处 |
|---|---|---|
| a | 标为 backtest；只有用当时真正可得的预报产出的才能叫 forecast | dashboard §10.2 ① |
| b | 点估计不单独出现，必带区间或稳定性比例 | dashboard §10.2 ② |
| c | 训练季内的格标为**样本内拟合**，不与留出格混称 | 本篇 |
| d | 不替换 `#/zone` 已有的两个答案，并列而不取代 | dashboard §10.2 ③ |

**③ 回溯线不动。** ADR 0013 §3（能回答「现在」的是官方工具的活）与
§4 第 3 条（不做地址输入 → 定位分区）继续有效。页面只讲**已经过去的事件**，
不出现「现在」「当前计划」「计划最近更新于」这类表述——最后一条还有一个
数据上的理由：排班源的六个字段里**没有任何更新时间**，能给的只有本项目的
采集日期（design §2）。

## 3. 被否决的方案

1. **保留 `load_score`，调权重或改顺位尺度（R4 / R5 原路线）。**
   否决：只要顺位还在分数里，任何正权重都会产生台阶。调小权重只改台阶高度，
   要让需求在事件内可见，唯一的办法是把顺位拿出分数。
2. **「计划差距 = 需求排名 − 排班排名」（伞篇 R6 原定义）。**
   否决：班次只有 5 个取值且大量并列（每个事件 5 个班次组全有人，22 个分区），
   拿它减一个 1–22 的名次，是在并列值上制造精度。何况台阶内的需求名次差
   中位只有 0.106 分，大半是噪声。
3. **判据不变，模型只留在叙事页的 Act V。**
   否决：那样 M1 唯一的公开形态仍是 F6 链，而 §1.1 已量出那条链在事件内几乎没有
   模型的声音。
4. **等 ADR 0014 结算（常规作业记录）再定方向。**
   否决：结算最晚 2026-12-31，且可能以沉默告终。本判据在现有公开数据上就能完成；
   若日后拿到常规作业记录，计划栏换数据源即可，**判据本身不变**。
5. **直接做前瞻（降雪前给估计）。**
   否决：预报快照至今零个雪季覆盖，第一批要等 2026-11（伞篇 R11）。
   前瞻是本判据在时间上的延伸，不是它的替代；同一张页面届时多一种「估计的来源」。
