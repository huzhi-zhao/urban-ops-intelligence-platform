## 1. 问题

M1 现在只在一个留出季上考过一次：2025-2026，7 个事件、154 格。那一次的 MAE 是
7.345，基线是 23.628。伞篇把这个样本量判为「名次随机」——一个季节换掉，名次就可能反过来。

R1 问「目标过度离散，换成负二项会怎样」，R2 问「往前滚多轮之后名次还稳不稳」。
R1 离开 R2 只能在 154 行上比出一个随机名次，所以两者一起做、一起签收。

本篇还要交付一个 R6 已经在等的结论：**区间的计数分布用泊松还是负二项**
（R6 design §6 第 4 项，「B 组之前，随 R1」）。R13 上线时用的是泊松，
154 个留出格上名义 90% 的区间实际只覆盖了 **77.922%**。

## 3. 约束

1. **同一套特征、同一信息边界。** 候选全部使用 `config/models/m1.yaml` 的 10 个特征
   （6 个事件特征、2 个日历特征、2 个 lag 特征）和 `log(unit_size)` 口径。
   不加 `shift_number` / `rank_factor`（`FORBIDDEN_FEATURES`），不加分区身份，不做特征工程。
   R1+R2 比的是分布族与学习器，不是特征。
2. **信息边界与 F5 相同，是「事件前一步」。** lag 特征严格因果：考季里第 3 个事件的
   `prev_target` 用的是第 2 个事件的实际计数。这是 F5 本来的口径，本篇**不**改成
   「季前一次性预测」。结论只能表述为事件前一步的回溯精度，不能外推到前瞻。
3. **时序切分，永不随机**（BO §4.4）。每一轮只用考季之前的季节训练。
4. **基线必须同台**（BO §4.4）。每一轮都报基线，基线就是现行的 `seasonal_naive`
   （因果扩展均值；L3 launch §3.3 指出它的日志名是错名）。
5. **不动 schema。** 评估产物落本地 `var/`，要进对象存储就落在既有的
   `gold/_forecast_runs/{model_version}/` 下，只追加。写生产前单独取得作者同意。
6. **模型版本显式。** 新增的版本前缀是 `m1-negbin-` 和 `m1-gbm-`。
   `m1-gbm-*` **永不作为服务版本**，它只用来反证（§4.1）。

## 4. 方案

### 4.1 候选

| 候选 | 实现 | 角色 |
|---|---|---|
| **基线** | 现行 `seasonal_naive` | 每一轮都报，不参与「选」 |
| **Poisson GLM** | 现行 `fit_poisson_glm`，offset = `log(unit_size)` | 现状 |
| **负二项 GLM（NB2）** | `statsmodels` 的 `NegativeBinomial(loglike_method="nb2")`，同样的 offset；α 在每一轮训练侧做 MLE | R1 的对照 |
| **GBM（重度正则）** | `HistGradientBoostingRegressor(loss="poisson")`，目标取 `count / unit_size`，`sample_weight = unit_size` | **只作反证**：重度正则下在滚动起点里赢不了 GLM，说明 GLM 没漏掉结构 |

GBM 的目标与权重写法跟 Poisson 加 offset **严格等价**：带权重 w 的率目标上的 Poisson deviance
是 `y·log(y/μ) − (y − μ)`，和计数目标上的 deviance 逐项相同。
GBM 需要把 `scikit-learn` 加进 `ml` extra，这是一个新依赖，已同意（§8 第 5 项）；
在批 3 随实现一起加，不提前加。

混合效应模型**不进**本轮候选（§8 第 2 项）。

**收敛失败就算这一轮失败**，不回落到别的族，也不换优化器重试，只报出来。
R13 的纪律同样适用：任何一轮失败，整批结果都不进结论。

排班期有 11 个季，一季一轮，训练窗口是扩展窗口（从 2008-2009 起，到考季之前）。
和现行 M1 一样，最早那个没有 lag 的事件不进训练。

| 3 | 2017-2018 | 3 | 66 | 52 |

照样报，但不进稳定性判据。

### 4.3 两处特征的因果性核查

- **`severity_score`** 在 `dim_snowfall_event` 里按 **99 个事件的全局 min–max** 归一化，
  归一化的上下界包含考季事件，严格说是泄漏。本篇的处理：
  - 对两个 GLM 候选，泄漏在数值上为零。每轮重算上下界时，
    `severity'` 是 `total_snowfall_cm` 与 `cold_c` 的另一组线性组合，而 `total_snowfall_cm`
    本身就是特征，所以 `{截距, total_snowfall_cm, severity}` 张成的列空间不变，拟合出的预测也不变。
    **要用单测证明**，不靠论证：用按训练侧重算的 severity 重拟合，预测逐格差 < 1e-9。
  - 对 GBM 不成立，因为树分裂对这种混合不具备不变性。GBM 一律用**按训练侧上下界重算**的 severity。
- **`season_index`** 是序数，因果。它对 GLM 意味着考季总在训练范围的线性外推端，
  对 GBM 意味着考季总落在最后一片叶子上。两种外推方式不同，但都如实报出，不修。

### 4.4 指标

**主指标只有一个：每一轮的格级 MAE。** 只有它进入名次稳定性的判据（§5.3）。
原因是它的单位就是工单数，而且在所有分布族下定义相同。

以下各项都报，但**不**参与「选」：

| 指标 | 定义 |
|---|---|
| 平均 Poisson deviance | 对每个候选的点预测 μ 用同一个公式 `model.poisson_deviance` 计算。它是 (y, μ) 的评分函数，不是模型自己的似然，所以跨族可比 |
| 按事件 MAE | 每个事件内格级 MAE，再报中位与最大 |
| 尾部 MAE | 实际计数 ≥ **训练侧**目标 P90 的考格上的 MAE；阈值按轮从训练侧取，不看考季 |
| 事件内排序 | 每个事件内预测与实际的 Spearman ρ，按轮报中位；前 5 名重合数（对应 R6 的 K = 5） |

🔴 **禁止比较**：负二项的对数似然或 deviance 与 Poisson 的 deviance 不是同一个量（伞篇 R1 判据）。
AIC 同理，不报。

### 5.1 复现门禁（对不上不得往下做）

- [x] 第 11 轮 Poisson 对 154 个留出格的预测与 F5 `m1-poisson-20260822-df31d954` 逐格差 < 1e-9，
      MAE 复现 7.345，基线复现 23.628
- [x] GLM 的 severity 不变性单测通过（§4.3）
- [x] 11 轮 × 4 个候选全部完成、失败 0；有失败就报出来，结论作废

### 5.2 分布族结论（交给 R6，可以先于 §5.3 单独交付）

这一项判的是**离散度**，不是名次。2,178 行估计一个离散参数，不受「154 行名次随机」的限制，
所以它不必等名次稳定性出结论。这正是它能把 R6 从关键路径上解开的原因。

- [x] 每一轮报 NB2 的 α 及其 95% 置信区间，同时报 Poisson 拟合的 Pearson χ²/df
- [x] 每一轮用点预测 μ 叠加计数分布，给出 plug-in 90% 预测区间，
      泊松（μ）与负二项（μ, α_轮）两种各算一次；在**第 1–10 轮**的考格上汇总覆盖率，
      按轮也报
- [x] **判定规则**（§6 第 3 项）：α 的 95% 置信区间在 ≥ 9/10 轮里不含 0，**并且**
      负二项的汇总覆盖率比泊松更接近 90%，那么 R6 改用负二项；否则保留泊松，
      并写明是哪一条没过
- [x] 不用那 154 个留出格的覆盖率做判定——77.922% 已经看过了（§2）
- [ ] R6 如果改用负二项，α 取「服务版本同一训练侧」上的 NB2 拟合值，并随 R6 的元数据一起冻结。
      均值模型仍是 Poisson GLM 的自助副本；「均值用泊松、噪声用负二项」的解耦要在 R6 方法说明里写明
      （§8 第 3 项）
      **R1 已选负二项；训练侧 α 的 R6 冻结与区间重算仍在 R6 批次。**

### 5.3 名次稳定性（R2 的主判据）

- [x] 每一轮报 4 个候选的 MAE 与名次，**模型与基线两侧都报**
- [x] 报**完整名次在多少轮里保持不变**；报 6 对候选两两之间「A 的 MAE 低于 B」的轮数
- [x] **稳定的门槛**（§6 第 2 项）：两两比较在第 1–10 轮里赢 **≥ 9/10**，才允许写「A 在滚动起点下
      稳定地低于 B」。单侧符号检验在无差异假设下，达到 9/10 的概率是 1.07%，达到 8/10 是 5.47%
- [x] 未过门槛的比较一律写「在 N 轮中赢了 k 轮」，不写方向性结论
- [x] GBM 反证：GBM 对 Poisson 与对负二项两对比较的轮数都报出。如果 GBM 过了门槛，
      说明 GLM 可能漏了结构，**记为 finding，不换服务模型**，交给 H2 之后处理
- [x] 分歧诊断（§8 第 4 项）：三个族（Poisson · 负二项 · GBM）逐事件的前 5 名，报在多少个
      事件上三者一致；**只报**，不参与判定

## 7. 被否决的选项

1. **随机 K 折或按事件的交叉验证。** 违反时序，而且 lag 特征会穿越。
2. **滑动窗口（固定长度训练）替代扩展窗口。** 早期几轮的训练事件已经只有 39–55 个，
   再截短就是在估计噪声。
3. **stacking、投票当交付物、对 GLM 做 bagging 提准。** 伞篇 R13 条下已经否决，理由不变。
   投票改作**分歧诊断**仍然成立（三个族在多少个事件上对前 5 名取得一致），列在 §8 第 4 项。
4. **拿负二项的 deviance、AIC 或对数似然去和泊松比。** 不同分布定义的量，不可比。
5. **按 R3 的 finding 挑模型。** 见 §5.5。
6. **季前一次性预测**（考季内 lag 特征不更新）。更接近前瞻，但改变了 F5 的信息边界，
   而且与 R11/R12 重叠；本篇不做。
