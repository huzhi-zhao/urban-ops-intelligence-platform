## 3. 渲染管线:验收判据的实际结果

新增 `scripts/presentation/render_html.py`(把 `var/presentation/<fig_id>.json`
渲染成自包含 `.html`,库与数据全部内嵌,不连 CDN、不用 `fetch()`——见 design C3)+
vendor 进仓库的 `scripts/presentation/vendor/echarts.min.js`(cdnjs 5.6.0,
2026-09-03 拉取,1.03 MB)。

**实现范围:12 个 `carrier: echarts` 图里,3 个已实现(`ranked_bar_whisker` /
`slope` / `scatter_fit` 三种图形类型),对应 FIG-BO2-01 / FIG-BO2-02 / FIG-BO2-04
——这三张恰好是 deck 主故事线里规格最明确的三张。其余 9 张的图形类型已在 §1
定案,渲染代码未写,原因不是拿不到 SQL 数据(和之前几轮 EDA 一样,线上环境要
用户自己跑 `make eda-export`),而是这批还没等到"先画完第一批再判断能不能抽
公共模板"这个 design §6 O4 的检查点。

判据与实测:

- `uv run --extra dev python -m pytest tests/unit/test_render_html.py -q`
  → **14 passed**。含一条"每个 `carrier: echarts` 的真实 fig_id 必须落在
  `FIGURE_SPEC`/`NOT_YET_IMPLEMENTED`/`OUT_OF_SCOPE` 三个桶之一、且只能落一个"
  的一致性测试——这是防止将来新增一个 `fig_*.sql` 却没人更新这个模块的门禁。
- `make lint` → 全绿(修了 3 条 ruff:未用变量、旧式 `Callable` 导入位置、
  多余的字符串类型注解)。
- `make test-unit-offline` → **1196 passed, 7 skipped**(此前基线 1181,
  +14 新增单测,0 回归)。
- **浏览器实测**:用 3 份 `tests/fixtures/presentation/*.json`(合成数据,
  仅 S/C 与 V/M 两组数字取自已发布的真实值,其余为占位,`_note` 字段与图注
  都显式标了 `[SAMPLE]`)渲染出的 3 个 `.html`,本地起 HTTP 服务器后在浏览器
  里逐张打开、读了 console——**0 条错误**,箱线图(横向、高亮 S/C)、斜率图
  (高亮 V/M、终点标签)、散点+双拟合线三种图形均正确渲染。

⚠️ 这 3 张渲染出的图**不是可以直接拿去用的交付物**——数据是合成的,只用来
证明管线本身能跑通、断网也能看。真正能上台的版本要在用户跑完
`make eda-export` 拿到真实 `var/presentation/*.json` 之后,用同一条命令重新
渲染一遍。

## 5. 决策记录(2026-09-03,用户核对后)

design §3.2 提出、本轮交流后已拍板的三项,记录结论,不再是待确认状态:

1. **FIG-BO4-02 维持 `carrier: echarts`,不改 Superset。** 见 §2 的偏差表——
   当初建议的理由(跟旁边矩阵配对展示)站不住脚,且这张 25 行的排名条形图
   被现场质疑、需要重算的概率很低,一句话能讲清楚,不必为此迁就载体。
   **已在 §1 表格与 `render_html.py` 的 `NOT_YET_IMPLEMENTED` 注释里同步。**

2. **FIG-BO6-03 deck 标注的措辞问题,记为 TODO 而非本轮任务。** 见上面 §4 L6——
   这是用户自己 deck 仓库的一行文案修改,本仓库不做。

3. **5 张未上台的图,原则上不再往 9-19 那份 pptx 里加。** 用户的原话是
   "ppt 是从叙事、演讲能力、时长的综合折中,我们这边是从纯技术角度,两者都需要
   妥协"——这条按 design C4 的"不是每个 `fig_id` 都必须变成一张台上的图"执行,
   不算砍需求,是这类图本来就有的一种合法归宿(留 Superset/仓库供追问)。

   **仅提一条可选的置换建议,供核对、不代为决定**:如果非要在"叙事冲击力"上
   跟现有附录比一比,**FIG-BO8-01(位移发散直方图)是唯一值得考虑塞进去的**,
   而且不必新增一张幻灯片——它可以作为附录 A8 的**同页配图**,跟现有的
   "位移不是优劣"那句 boundary 文字挨在一起,像 FIG-BO2-02 之于主故事线
   slide 10 那样("斜率图不画就等于在说十年没变")。理由:A8 现在的
   "两个模型版本移动格数一样多"是整份 deck 里**唯一一句只靠文字断言、
   没有图能让人自己核对的高风险表述**;其余四张(FIG-BO1-02/BO3-01/BO3-03/
   BO6-02)对应的结论在正文/附录里都已经有对应文字撑着,图只是加分,不是
   补一个"裸断言"的洞。**没有找到值得为此牺牲的现有附录页**——A1–A9
   九页各自撑着一个真实会被问到的风险点,拿掉哪张都在减防守面,所以这条
   建议是"加进 A8 内部",不是"换掉某一页"。是否采纳仍由你判断。
